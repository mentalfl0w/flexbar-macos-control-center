# Icons

These PNG icons are generated from SF Symbols by the build script.

To regenerate:

```bash
cd mac-control-center
bash scripts/build-icons.sh
```

This requires macOS with Swift (Xcode Command Line Tools). The rendered
icons are 48x48 white PNGs suitable for dark Flexbar key backgrounds.
